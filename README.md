# gaberighter/tap

A Homebrew tap for my own tools.

## Excalibur

A small floating window for macOS that shows system metrics. Apple Silicon only. Source: <https://github.com/gaberighter/excalibur>.

```sh
brew install --cask gaberighter/tap/excalibur
```

To update:

```sh
brew upgrade --cask excalibur
```

The app is not notarised by Apple. The cask clears the quarantine flag after installing so that the app opens.
